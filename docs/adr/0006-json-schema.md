# ADR-0006: JSON output format and schema versioning

- Status: Proposed
- Date: 2026-11-07

## Context

JSON output is a contract for CI pipelines and agents.

## Options

- Versioned schema with an integer `schema_version`.
- Unversioned output, document changes in release notes.

## Decision

Recommended: integer `schema_version`, bumped on every incompatible change; new optional fields do not bump it. A JSON Schema is generated by `xtask` and published. No host-identifying fields exist in the schema.

## Consequences

- Snapshot and schema-validation tests for every release.
- Breaking changes require a major schema version and a release note.
